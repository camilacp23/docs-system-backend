## Deployment incidents (2026-11-19)

Problems met while deploying to Render. They are lessons for the procedure, not faults of a person. The commands and variables
of the procedure are in D-155 and in [OPERATIONS_NOTES.md](OPERATIONS_NOTES.md). Exact error texts that were not kept are
marked as not recorded.

| # | Symptom | Cause | Correction | How to avoid it |
| - | ------- | ----- | ---------- | --------------- |
| 1 | The build of the API failed with exit code 127 (command not found). | The Build Command field of Render held a mix of the default value and the intended command. | The field was replaced entirely by `npm ci --include=dev && npx prisma generate && npm run build` (D-155). | Clear the field before pasting the command and compare it with D-155 before saving. |
| 2 | The build failed at `npx prisma generate`. Exact text: not recorded. | `prisma generate` reads `prisma.config.ts`, which requires `DATABASE_URL`, and the URL of `docs_owner` is deliberately not stored in Render. | A placeholder `DATABASE_URL` was set for the build. It connects to nothing (D-155). | Include the placeholder `DATABASE_URL` in the list of build variables of the procedure. |
| 3 | The API failed with error 42501 (insufficient privilege) on the table `app_user`. | `APP_DATABASE_URL` used the default user of Render Postgres instead of `docs_app`, which holds the grants of the migrations. | `APP_DATABASE_URL` was set with the `docs_app` user. | Check the user name inside the URL before saving it: the API connects only as `docs_app` (rule 4 of `CLAUDE.md`). |
| 4 | The passwords that were meant to be set were not the ones the roles and the administrator account kept. They were pasted with Ctrl+V in Git Bash and other values were stored. Exact error: not recorded. | Ctrl+V did not paste the intended text into the silent prompt of `read -rs` in Git Bash. | The roles were reassigned with `ALTER ROLE`, and the hash of the administrator was replaced connecting as `docs_app`, so the change was audited. | Verify each password by connecting as that role before going on, and use the paste method of the terminal that was checked to work (not Ctrl+V in Git Bash). |
| 5 | The Static Site got a suffix in its name, so its URL was not the one chosen. | The chosen name was not available, and Render added a suffix. | The real URL shown by Render was used. Other details: not recorded. | Read the final URL on the service page right after creating it, and use that value everywhere it is needed. |
